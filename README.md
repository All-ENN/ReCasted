# ReCasted


**Target:** *Ratchet & Clank (PS4)*
- **CUSA01073 v1.09 (EU)** — Status: Fully Playable
- **CUSA01047 v1.09 (USA)** — Status: Supported

ReCasted is a minimal, lightweight High-Level Emulation (HLE) compatibility layer and native PC loader designed to execute *Ratchet & Clank (PS4)* directly on host x86-64 hardware without full-system emulation or virtualization overhead.

By bridging Sony Orbis OS system calls and the Liverpool GNM graphics pipeline directly into Win32/Linux POSIX APIs and Vulkan 1.3, ReCasted allows the unmodified game binary to execute as a native host process.

**This repository is a mirror.** The main project lives at [GitLab](https://gitlab.com/AndyALRLabs/ReCasted/). Releases are published here as well.

Platforms: Windows, Linux

Requirements: a legally obtained copy of the game (version 1.09). No game files are included in this project.

Status and known issues: see the GitLab repository.
